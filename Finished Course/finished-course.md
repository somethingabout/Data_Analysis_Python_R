## What I learned about GitHub
### Repositories
A repository is the main place where a project lives, it holds the files and also keeps track of the project’s history.

### Commits
A commit is like a saved checkpoint, it records changes I made and includes a short message explaining what I changed.

### Branches
A branch is a separate workspace inside the same repository, it lets me try changes without affecting the main branch until I’m ready.

### Pull Requests
A pull request is how I ask to merge my branch into the main branch and It also gives the instructor a clear way to review my work.

### Issues
Issues are used to track things that need to be done, like tasks, bugs, or ideas for improvement.

## What I learned about Markdown
Markdown is a simple way to format writing on GitHub.

### Headings
I learned that headings use the `#` symbol:
- `#` makes a big title
- `##` makes a section heading
- `###` makes a smaller subheading

### Lists
I can organize information using bullet points:
- Like this
- And this

Or numbered lists:
1. First step
2. Second step
3. Third step

### Styling text
I learned basic ways to style text:
- Bold: **bold text**
- Italic: _italic text_
- Strikethrough: ~~crossed out~~
- Code formatting: `git status`
